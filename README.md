# collectorshaven

A mobile app for collectors built with Expo and React Native.

[Edit in StackBlitz next generation editor ⚡️](https://stackblitz.com/~/github.com/jamesmelanson24/collectorshaven)

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Linting

Linting uses the Expo CLI. After installing dependencies, run:
```bash
npm run lint
```
If you encounter `expo: command not found`, ensure `node_modules` is present or run:
```bash
npx expo lint
```
